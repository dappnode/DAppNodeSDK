# Security Policy

## Security contact

Eduardo Antuña Díez ([@eduadiez](https://github.com/eduadiez))
is a security maintainer for this project, responsible for coordinating
vulnerability triage, remediation, and disclosure.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to [admin@dappnode.io](mailto:admin@dappnode.io) or [edu@dappnode.io](mailto:edu@dappnode.io).

Do not disclose vulnerability details in a public GitHub issue.
